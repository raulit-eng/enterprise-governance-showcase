## 🔍 Methodology: Forensic Profiling & Backward-Design

Most data cleanup treats symptoms in place and risks silent data loss. Every engagement follows a **Forensic Backward-Design Methodology**:

1. **Define the Clean Target End-State:** Start from the exact import-ready schema, reconciled financial ledger, or executive KPI view required at the finish line.
2. **Preserve the Scene First (Immutable Staging):** Never modify raw inputs in place. Every engagement begins by sealing an untouched copy with a **SHA-256 Chain-of-Custody** fingerprint.
3. **Zero-Config Schema Detection & Root-Cause Tracing:** Dynamic pattern profiling automatically detects emails, phones, dates, currency amounts, quantities, and IDs without requiring manual schema templates—catching duplicates, cross-column math errors, and entry typos (`$5` vs. `$500`).
4. **Deliver Clean Data + Transparent Audit Proof:** Return an executive-formatted Excel/CSV deliverable alongside a dedicated quarantine report and Before/After HTML Scorecard documenting every resolved record.
